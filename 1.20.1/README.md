# Much More Dungeons — Minecraft 1.20.1

Fabric and Forge workspace for Minecraft 1.20.1 (Java 17). The mod itself is documented in the [repository root README](../README.md);
building, running and QA are described in [CONTRIBUTING.md](../CONTRIBUTING.md).

```bash
./gradlew build      # jars in */build/libs/, unit tests included
```

Shared code lives in `common/`; the loader modules only register content and commands. The JSON data under
`common/src/main/resources/data/` is generated by `tools/datagen.py` and the templates by `tools/templates.py` and
`tools/generate_soulfire_crypt.py`: edit those, not the generated files.
