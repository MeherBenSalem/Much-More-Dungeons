# Much More Dungeons

Much More Dungeons adds handcrafted dungeon content to Minecraft 1.20.1 with support for both Fabric and Forge. The current release focuses on a surface tower dungeon that blends into the overworld and rewards exploration with useful early-to-mid game loot.

## Short Description

Explore the overworld for tower dungeons packed with loot, supplies, and rare rewards. Much More Dungeons adds a handcrafted structure that spawns naturally in several forest and plains-style biomes on both Fabric and Forge.

## Features

- Adds the Tower Dungeon structure to world generation
- Supports both Fabric and Forge on Minecraft 1.20.1
- Uses a handcrafted NBT structure for a consistent dungeon layout
- Spawns naturally in Plains, Forest, Taiga, Birch Forest, and Dark Forest biomes
- Uses random spread placement for balanced exploration and discovery
- Integrates with Minecraft's jigsaw worldgen system for stable structure placement
- Includes chest loot tuned for useful progression instead of overpowered rewards

## Tower Dungeon Highlights

- Surface structure with terrain-aware placement
- Built to feel like a discoverable overworld landmark
- Suitable for adventure, exploration, and survival progression
- Loot can include iron, gold, emeralds, diamonds, redstone, food, golden apples, and enchanted books

## Loot Style

Tower Dungeon chests are designed to feel rewarding without skipping progression. Loot pools include common supplies for survival runs, mid-tier valuables for momentum, and a small chance at rarer items for memorable finds.

## Compatibility

- Minecraft 1.20.1
- Fabric
- Forge
